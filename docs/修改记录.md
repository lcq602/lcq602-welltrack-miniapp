### 修改内容
- 将模板替换为原生小程序首页、计划、记录、运动、分析和个人资料页面，统一通过 `wx.request` 调用 FastAPI。
- 新建参数校验、用户会话、资料版本、每日记录、运动记录、首页与周期汇总、CSV/JSON 导出 API；SQLite 查询按已认证用户隔离。
- 增加本地匿名会话和服务端微信 code 验证入口，密钥仅从环境变量读取；新增 SQL 参数化、输入范围校验和 CSV 公式转义。
- 使用 uv 管理依赖并生成锁文件；加入本地配置样例、启动脚本、结构说明和 API 文档入口。
- 移除小程序项目配置中的 AppID，忽略本地私有配置、数据库、密钥和导出文件。

### 影响范围
影响小程序页面、FastAPI 接口、SQLite 初始化 schema 和本地启动流程。主要接口位于 `/api/v1`，API 文档由 FastAPI 提供。数据库文件默认写入 `data/welltrack.sqlite3`。

### 风险与注意事项
按用户确认，本迭代只授权读取与新增：日常记录及运动没有编辑/删除 API，同一用户同一天重复记录返回 409；JSON 只支持导出，导入恢复暂未实现。提醒偏好可保存，但微信订阅消息模板及实际推送未接入。没有可靠性能基准，无法定量验证 5% 性能约束；微信开发者工具真机/模拟器界面尚未验证。

### 修改内容
- 将全部小程序入口、页面、工具与微信项目配置移动到 `miniprogram/`，README 指导开发者工具直接导入该目录。
- 将 uv 项目文件、锁文件、环境样例和启动脚本收拢到 `backend/`，后端可从该目录独立执行 `uv sync`、测试和 Uvicorn。
- 调整后端模块导入、SQLite 默认数据目录和启动命令，数据库默认写入 `backend/data/`。
- 更新根目录总览及忽略规则，继续排除私有小程序配置、环境变量、虚拟环境和数据库。

### 影响范围
项目目录组织和本地启动命令；API 请求路径和小程序页面功能不变。微信开发者工具应导入 `miniprogram/`，Python/uv 命令应在 `backend/` 执行。

### 风险与注意事项
已有根目录 `.venv` 是此前在根目录执行 uv 时生成的旧环境；新的后端环境已建立在 `backend/.venv`，请只使用后端目录内的命令。根环境清理操作被本机策略拒绝，因此旧环境目录暂时保留且由忽略规则排除。
